Engineered Rigor

Strict 4-Tier Layered Architecture

Designed for Software Development & Architecture (SDA) standards. The user interface never communicates directly with the database—every transaction flows strictly through decoupled contracts.

1. Presentation Tier Vanilla HTML5/JS/jQuery client + Express 5.x API controllers.
2. Business Logic Tier Enforces booking collision detection, attendance rules, and course capacity ceilings.
3. Data Access & Persistence Tier Repository abstractions over MongoDB & Mongoose schemas.
Architecture Data Flow REST / JSON 
Browser (HTML / JS / Anime.js)
       │ (HTTP POST /api/attendance)
       ▼
[ Presentation Layer ]  ──> attendanceController.js
       │ (markAttendance)
       ▼
[ Business Logic Layer ] ──> Idempotent date reconciliation & validation
       │   ├── checkThresholds()

       ▼
[ Database Layer ]      ──> MongoDB / Embedded In-Memory Engine
